# Spec: русификация Metroid Prime для нативного порта

## Цель
Владелец проходит Metroid Prime (GameCube USA 1.00) в нативном порте Odrannnn/MetroidPrimePort
на русском: меню, HUD-сообщения, подборы, сканы, логбук, концовки. Поставка — папка-мод
`russian` для `mods/` порта; диск и порт не меняются (ADR 0001).
Позже: тот же перевод поверх контента Remastered (Switch) (ADR 0004).

## Предположения (проверяются по ходу; статус меняется здесь)

## Команды
```
python -I tools/extract.py "Metroid Prime (USA).iso" work   # распаковка (T1)
python -I tools/dump_en.py work text/en.json                 # английский исходник (T2)
python -I tools/preview_font.py work/res/FONT/<id>.FONT work/res/TXTR out.png "текст"
tools/test.sh                                                # все проверки = CONSTRAINTS.md
MP_USER_PATH=work/user MP_MODS=mod ./MetroidPrime-x86_64.appimage "Metroid Prime (USA).iso"
```

## Структура
```
tools/        python: mp (диск/PAK), strg, font, extract, dump_en, preview_font, test_*
text/         ru.json, glossary.md (в git); en.json (вне git)
docs/         SPEC.md, adr/, tickets/
work/ mod/    вне git: распакованное, превью, user-папка порта, собранный мод
```

## Стиль кода
Python stdlib + Pillow, без классов там, где хватает функций; модуль на формат
(`strg.py`, `font.py`) с парой `parse_*/build_*`; докстринг модуля описывает бинарный формат
со ссылкой на файл декомпиляции. Комментарии — «почему». Скрипты запускаются `python -I`.

## Тестирование
- Форматы: round-trip `build(parse(x)) == x` на всех ресурсах диска (`tools/test_roundtrip.py`).
- Перевод: валидатор (T7) — теги, число строк, покрытие глифами, хеш исходника.
- Шрифты: каждый символ ru.json есть в каждом шрифте, где встречается его таблица; превью PNG.
- В игре: скриншоты ключевых экранов из порта с изолированной user-папкой.

## Границы
- **Всегда:** `tools/test.sh` перед коммитом (хук); порт только с `MP_USER_PATH=work/user`;
  ветка на тикет; ADR до архитектурного решения; «проверить» на незамеренном.
- **Спросить сначала:** новая зависимость или скачивание; любые правки порта; запуск порта не в
  изолированной папке; смена принятого ADR; публикация чего-либо наружу.
- **Никогда:** данные Nintendo/бинарники в git; запись в ISO; ослабление CONSTRAINTS.md ради прохождения проверки.

## Критерии успеха
1. Переведены все 1818 уникальных строк (2323 вхождения); ratchet-счётчик в CONSTRAINTS = 2323.
2. `tools/test.sh` зелёный: 0 ошибок валидатора, 0 символов без глифа.
3. Скриншоты без переполнений и пропавших букв: экран сохранений, главное меню, пауза/опции,
   карта, скан (короткий и длинный), логбук (все категории), сообщение о подборе, концовка.
4. Владелец апрувит пачки перевода (выборочно, по скриншотам).

## Открытые вопросы
- Шрифт титров `30707C0C` (Arial Unicode MS, японский набор) и `9BB52E75` (`Deface18B#`, 12 глифов):
  где используются и нужна ли им кириллица — T3.
