# ADR 0001: мод-папка порта, русский вместо секции ENGL

## Статус
Принято

## Дата
2026-10-21

## Контекст
Нужно играть в Metroid Prime на русском в нативном порте Odrannnn/MetroidPrimePort.
Порт читает диск пользователя и подмешивает моды из `mods/<имя>/`: файл
`<8hex>.<TYPE>` (`0552A456.STRG`, `….FONT`, `….TXTR`) подменяет ресурс во всех PAK,
диск не меняется (docs/MODS.md порта, `platform/port_mods.cpp`). Моды применяются
по имени папки, поздний выигрывает.

`CStringTable` порта декодирует все языковые секции STRG и показывает ту, чей код
равен `text_language`; при пустом значении — `ENGL`. На USA-диске у всех 1293 таблиц
одна секция `ENGL`.

## Решение
- Перевод поставляется как мод `russian`: изменённые STRG, а также FONT/TXTR с кириллицей.
- Русский текст пишется **в секцию `ENGL`**, остальные секции STRG сохраняются как есть.
- Код порта не правим.

## Рассмотренные альтернативы

### Отдельный язык `RURU` в STRG
- За: английский остаётся рядом, язык переключается в F1.
- Против: шрифт под язык порт подменяет только для PAL-кодов (`FRasterFontFactory`,
  `kPalLanguages`); выбор языка в F1 — фиксированный список. Нужен патч порта.
- Отклонено: патч порта против правила «порт не трогаем» и ломается на каждом обновлении.

### Патч PAK целиком (`Metroid2.pak` и т.д.)
- За: не зависит от механизма loose-ресурсов.
- Против: сотни МБ данных Nintendo в моде; конфликт с любым другим модом, меняющим PAK.
- Отклонено: loose-ресурс по id делает то же точечно.

### Патч ISO
- Против: нарушает «диск только читается», не работает с выбором образа в порте.
- Отклонено.

## Последствия
- В режиме мода английского текста нет; вернуть — выключить мод (F1 > Mods).
- Если в порте выбран FR/DE/… (`text_language`), русский не виден: порт берёт секцию языка и подменяет
  весь FONT шрифтом импортированного PAL-диска (`FRasterFontFactory`) → инструкция установки.
- Строки, захардкоженные в коде игры и порта (SPEC A7), остаются английскими.
- Randomizer и Archipelago порта переписывают строки STRG английскими во время игры.
- Наш FONT подменяется для всех языков, поэтому латиницу в нём менять нельзя.

- Порт: AppImage v0.31.1, `--version` → `0.31.1 (247192bbabe1)`, SHA-256
  `57f7501ca9f98eb388e6f52a8a8b91394ac9cedcd426b4a857cf8b85e4a74b52` (2026-10-22; до этого
  `01c389607ab8`). Срез на v0.31.1 проверен: мод грузится (348 ресурсов), главное меню, HUD и
