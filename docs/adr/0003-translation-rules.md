# ADR 0003: правила перевода

## Статус
Принято; спорные термины решены на Чекпоинте 2 (2026-10-22)

## Дата
2026-10-22

## Контекст
1818 уникальных строк (2323 вхождения): меню, подборы, сканы, логбук. Владелец играет сам;
экономия токенов допустима на процессе, **не на качестве перевода**. Русская фанатская Metroid Wiki
даёт устоявшиеся названия для ~90 из ~200 ключевых терминов.

## Решение
- **Ключ** строки — `strgId:index`, у каждой записи хеш исходника (`en`, sha1[:8]); сменился исходник —
  перевод не применяется, валидатор падает (T5, T7). Для Remastered — `msbt:<label>` (ADR 0004).
- **Термины** — только по `text/glossary.md`. Источник: рувики → если нет, перевод по смыслу
  (Ice Beam → Ледяной луч, Plated Beetle → Бронежук, как делает сама вики) → придуманные имена
  существ транслитом (Eyon → Эйон, Jelzap → Джелзап).
- **Регистр**: с заглавной первое слово и имена собственные (Ледяной луч, Руины Чозо, Таллон IV);
  заглавная вики в каждом слове — нормализуется. Строки, целиком набранные заглавными в оригинале
  (MAIN MENU), — заглавными.
- **Типографика**: «ёлочки», ё всегда, тире —, многоточие …; слитно «супер-» (Суперракета).
- **Теги** `&…;` переносятся без изменений и в том же количестве; `&image=` (кнопки) стоит там же
  по смыслу фразы.
- **Переносы `\n`** английского — под его длину: в русском переразбиваются, где строка в фиксированном
  окне (подсказки, кнопки); в сканах и логбуке перенос делает порт.
- **Стиль**: сканы и данные пиратов — сухой отчётный тон (это вывод компьютера костюма и перехваченные
  рапорты); знания Чозо — торжественный, архаичный, без канцелярита; интерфейс — коротко, глаголы в
  инфинитиве или повелительном (Выбрать, Назад). К игроку — на «вы» в системных сообщениях.
- **Точность важнее краткости** (владелец, 2026-10-22): смысл не сокращается ради места. Не влезает —
  перенос по слогам, вторая строка; если и так нельзя — решает владелец.
- **Длина**: поля интерфейса проверяет валидатор по FRME (T7b); не влезающее в замеренный предел не
  коммитится, превышение оригинала без замера — список скриншотов.
- **Весь перевод делает основная модель**; каждая пачка — тикет с выборочной вычиткой владельцем.

## Рассмотренные альтернативы

### Дешёвая модель на шаблонные пачки (сканы существ, подборы)
- За: в разы меньше токенов.
- Против: качество и единство стиля; владелец явно запретил экономить на качестве.
- Отклонено.

### Транслитерация всех названий (Power Beam → Пауэр-бим)
- Против: в русском фан-сообществе устоялись переводы (Ледяной луч, Морфо-шар); транслит хуже читается.
- Отклонено.

### Регистр вики как есть (Энергетический Костюм)
- Против: противоречит русской орфографии, выглядит как калька с английского Title Case.
- Отклонено: формы вики берём, регистр нормализуем.

## Последствия
- Глоссарий обязателен; новый термин сначала в глоссарий, потом в перевод.
- Спорные термины решаются один раз на Чекпоинте 2 и не переспрашиваются.
