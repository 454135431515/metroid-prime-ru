# P2: подготовка к публикации на GitHub

Ветка: `p2-publish` · Статус: done · Размер: S
Зависит от: Tn

## Цель
Репозиторий можно выложить: понятно, что это и как собрать мод из своего диска; ясны лицензии;
в истории нет личных данных.

## Решение
Вариант «только исходники»: собранный мод не раздаётся (в нём изменённые файлы Nintendo), каждый
собирает его сам двумя командами. Код — MIT, перевод и глоссарий — CC BY 4.0. Автор коммитов —
адрес noreply GitHub (история перезаписана до публикации). Репозиторий `metroid-prime-ru`,
сначала приватный.

## Критерии приёмки
- [x] `README.md`: что нужно, сборка, куда класть мод, Remastered
- [x] `LICENSE` (MIT), `text/LICENSE` (CC BY 4.0)
- [x] приватный репозиторий на GitHub, push main

## Проверка
- [x] сборка с нуля по README (`extract.py` + `build_mod.py`) совпадает с рабочим модом
- [x] в истории нет личной почты
