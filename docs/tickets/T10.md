# T10: прогон на вылеты по всем комнатам

Ветка: `t10-crash-sweep` · Статус: in progress · Размер: S
Зависит от: T9

## Цель
Мод не роняет порт при загрузке ни одной комнаты: после вылетов у лифта (T5b) и у ящика (T7f) —
систематическая проверка, а не по жалобам.

## Решение
`tools/crawl.py`: порт с модом и консолью (`MP_CONSOLE`) на копии user-папки (`work/user-crawl`),
игра со слота A, затем `warp <MLVL> <MREA>` в каждую комнату каждого мира (список из PAK диска) и
ожидание N кадров. Вылет — порт перестал отвечать: строка в отчёте, хвост лога, перезапуск и
продолжение. Ошибки загрузки ресурсов из лога (`failed to load`, `Truncated`) — в отчёт.

## Критерии приёмки
- [x] пробный прогон: Фрегат, 28 комнат — 0 вылетов, 0 ошибок ресурсов; комнаты по логу посещены
- [ ] все миры: 0 вылетов или каждый вылет повторён без мода и разобран
- [ ] не ловит: вылеты от действий (бои, катсцены, разрушаемые объекты) — только живая игра
