# T3: формат FONT/TXTR, где какой шрифт, ADR 0002

Ветка: `t3-fonts` · Статус: done · Размер: M
Зависит от: T1

## Цель
Знать формат шрифтов настолько, чтобы дописывать в них глифы без потерь.

## Критерии приёмки
- [x] `tools/font.py`: FONT v2 и TXTR C4, round-trip 7/7 + 7/7 в `test.sh`
- [x] `tools/preview_font.py`: атлас с рамками глифов и строка по метрикам игры
- [x] ADR 0002 с решением по кириллице

## Проверка
- [x] `tools/test.sh` зелёный
- [x] `work/preview/*.png` — атласы всех шрифтов

## Итог
- Палитра атласов: 0 фон, 1 заливка, 2 контур; глифы 1-битные.
- Текст переключает шрифт тегом `&font=<id>;`: `B7BBD0B4` (надписи мира), `30707C0C` (японские
  имена в титрах), `C29C51F1` (UI). Остальное — шрифты по умолчанию у виджетов FRME.
- В шрифтах нет «», —, …, ’, ° — английский текст уже содержит …’° (2–4 раза), они просто не рисуются.
- SPEC A5 закрыто: в верхний регистр отображаемый текст не переводится.

## Независимое ревью
Блокеров нет. Внесено: атлас — степень двойки, `kern_start` новых глифов, SPEC A4 уточнено,
A7 ложно (захардкоженные строки — английские без патча порта), ADR 0001 — подмена FONT PAL-шрифтом
при выборе PAL-языка, randomizer/Archipelago. Подтверждено по коду: A1, A3, A5, выбор ENGL,
порядок модов (`remastered-models` < `russian`), форматы `strg.py`/`font.py`, кириллица в
переносе строк (ранг 5 в `CWordBreakTables.cpp`).
