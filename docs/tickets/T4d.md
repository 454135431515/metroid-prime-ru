# T4d: отдельная строчная «б»

Ветка: `t4d-lowercase-be` · Статус: done · Размер: S
Зависит от: T4c

## Цель
Строчная «б» не выглядит как заглавная «Б» (замечание владельца по журналу: «Боевой», «Биоинженерии»).

## Критерии приёмки
- [x] «б» = чаша строчной «о» + флажок: ступенчатая диагональ от верха чаши вверх направо
- [x] не путается с «Б» (плоский верх во всю ширину) и с латинской b (без флажка) — превью всех кеглей

## Итог
Раньше «б» была копией цифры «6» — в Deface это тот же силуэт, что «Б». Восхождение над x-высотой
всего 2–3 строки, поэтому прямой флажок сливался с чашей; диагональ — в стиле диагоналей Z шрифта.
