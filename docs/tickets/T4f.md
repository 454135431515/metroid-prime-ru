# T4f: строчная «б» — уменьшенная «Б»

Ветка: `t4f-be-flag` · Статус: done · Размер: S
Зависит от: T4d

## Цель
«б» не выбивается из строки (скриншот владельца: «Забрала» в кнопке паузы).

## Решение
Строчные Deface — капитель: «в», «д», «и», «л» — заглавные на x-высоте. «б» из T4d с рукописным
флажком до высоты заглавных одна торчала над строкой, а флажок в 1–2 px на мелком кегле читался
обрывком. Теперь «б» = `low(cap_Б)`: плоский верх во всю ширину отличает её от цифры 6.

## Критерии приёмки
- [x] превью трёх шрифтов (кнопки паузы 192BB274, контурный C29C51F1, 13B)
- [x] владелец: в игре «б» на месте
