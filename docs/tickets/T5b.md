# T5b: ресурсы мода кратны 32 байтам (вылет у лифта на порте 0.31.1)

Ветка: `t5b-align-resources` · Статус: done · Размер: S
Зависит от: T5, T7d

## Цель
Игра на порте 0.31.1 не вылетает при загрузке мира с модом.

## Критерии приёмки
- [x] причина по логу владельца: порт отдал добавленный в NoARAM.pak шрифт `52550001` с размером,
      округлённым вниз до 32 (9152 из 9173 байт), следующий ресурс (`2F972D0C`, HUD) прочитан со сдвигом
      → `Truncated resource stream`, SIGABRT при подъёме на лифте
- [x] `build_mod.py` добивает каждый файл мода до кратного 32 размера (FONT/TXTR — нулями, STRG — 0xFF,
      как в PAK диска); проверка в `tools/test_build_mod.py`
- [x] в игре: загрузка сохранения и переход в Руины Чозо без вылета, HUD-сообщение узким шрифтом
