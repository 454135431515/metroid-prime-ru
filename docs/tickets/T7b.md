# T7b: проверка вёрстки по реальным полям интерфейса (FRME)

Ветка: `t7b-panes` · Статус: done · Размер: M
Зависит от: T7, T8.1

## Цель
Переполнение текстового поля ловится валидатором до запуска игры, а не на скриншоте владельца.

## Критерии приёмки
- [x] размеры всех 189 текстовых полей берутся из FRME диска (`tools/frme.py`)
- [x] привязка строк к полям — по коду декомпиляции (`text/panes.json`, 28 правил с источником)
- [x] превышение замеренного в игре предела — ошибка; превышение оригинала без замера — «проверить в игре» со списком экранов

## Проверка
- [x] `tools/test.sh` зелёный
- [x] калибровка: поля кнопок паузы в FRME — 120 px Head14B, ровно порог, выведенный из скриншотов T8.1
- [x] ловит реальный случай: «Королева паразитов» на полоске босса (скриншот владельца)

## Итог
- FRME не ограничивает видимую область: поля без переноса показывают текст шире своей ширины
  («Бонусы связи с Metroid Fusion» в поле 132 px), поля с переносом — больше строк, чем помещается
  в их высоту (HUD-сообщения оригинала — 4–5 строк в поле на 2). Надёжны только ширина поля с
  переносом и пределы, замеренные в игре. Поэтому допуск по умолчанию — английский оригинал того же
  поля, а предел из скриншота (`max`, `lines` в `panes.json`) делает проверку жёсткой.
- Замерено: рамка босса 170 px (видимая часть обрезанной строки), кнопки паузы 3 строки,
  нижняя панель паузы, «Масштаб».
- Исправлено по новой проверке и правилу владельца «ни единицы информации не терять»:
  «Королева паразитов» в две строки (проверить скриншотом), «Прочее» → «Доп. снаряжение»,
  «Видимость» → «Непрозрачность» забрала/шлема, «Пройдено» → «Процент прохождения»,
  «Сложный режим» → «Включён сложный режим».
