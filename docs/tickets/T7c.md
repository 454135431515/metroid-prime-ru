# T7c: проверка наложения текста соседних полей

Ветка: `t7c-overlap` · Статус: done · Размер: M
Зависит от: T7b

## Цель
Текст одного поля не наваливается на текст соседнего — нигде, проверка без запуска игры.

## Критерии приёмки
- [x] мировое положение каждого виджета из FRME (цепочка родителей, поворот)
- [x] прямоугольник реального текста поля: ширина в пикселях шрифта × dimX/extentX, выравнивание, pivot, строки
- [x] ошибка, если русские прямоугольники соседних полей пересекаются, а английские — нет

## Проверка
- [x] модель повторяет скриншот владельца: «Обычный режим» (до −4,58) налезает на «Сложный режим» (с −8,66);
      по-английски между ними зазор
- [x] `tools/test.sh` зелёный, негативный тест на наложение

## Итог
- `tools/frme.py`: `widget_starts`, `world_transforms`, `text_box`. Все создатели виджетов кончаются
  `ParseBaseInfo` (`CGuiFactories.cpp`, 13 типов), поэтому положение любого виджета читается с хвоста
  перед следующим, без разбора тел всех типов; разбираются все 21 кадр диска.
- Исключения (`_exclusive` в `panes.json`): строка выбора режима подменяет строку своего слота;
  подписи меню лучей и забрал не видны одновременно (проверить).
- Найдено и исправлено: строка выбора режима — «Обычный | Сложный» (решение владельца); две строки
  проверка отвергла — залезают на слот ниже.
- Покрытие: проверяются поля, у которых в `panes.json` есть строки. Новые экраны требуют правил.
