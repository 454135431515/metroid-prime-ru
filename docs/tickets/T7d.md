# T7d: узкий шрифт для имени босса

Ветка: `t7c-overlap` (вместе с доработками T7c) · Статус: done · Размер: S
Зависит от: T7c

## Цель
«Королева-паразит» на полоске босса целиком и с зазором до скобок рамки, без потери слов.

## Критерии приёмки
- [x] узкая копия 13B (`52550001`/`52550002`, нет ни в одном PAK): из каждой буквы убрана одна колонка
      из самой длинной серии одинаковых внутренних колонок — сужаются просветы, стемы прежние
- [x] `textpane_boss` в трёх кадрах HUD (боевой, тепловой, рентген) ссылается на неё; кадр отличается
      от диска ровно 4 байтами (тест)
- [x] скриншот боя: зазор до скобок, кнопки паузы и настроек чистые (скриншоты владельца)

## Проверка
- [x] «Королева-паразит» 176 → 160 px, «Метроид Прайм» 154 → 142, «Parasite Queen» 139 → 127
- [x] `tools/test.sh` зелёный; валидатор меряет поле шрифтом из правила (`font` в `panes.json`)

## Итог
Единый источник: поле `font` правила `boss` в `text/panes.json` читают и `build_mod` (патч FRME),
и валидатор (ширина и наложения).

## Доработки T7c в этой же ветке
- Тексты для проверки наложения собираются по правилам (суффикс процента — только у сохранённых слотов).
- Высота текста — строки шрифта, а не высота поля; повёрнутые в 3D поля (боковые панели паузы)
  в проверку наложения не входят — плоская проекция для них неверна.
- Правила для 60 → 90+ полей: строка слота (регион, «в игре»), все кнопки паузы, меню настроек
  главного экрана, GBA, подписи карты, прокрутка сканов; непокрытое перечислено в `_uncovered`.
- Найдено: пункты настроек (`500EC6A0:16–35`) выводятся и в узких кнопках паузы, и в меню настроек
  главного экрана без переноса — ручные `\n` там дали бы 2–3 строки поверх соседних пунктов.
  Пункты переписаны без `\n` так, чтобы каждое слово влезало в кнопку: «Контроллер»,
  «Видимость забрала/шлема» (слово «Непрозрачность» шире любой кнопки), «Сдвиг экрана: X/Y»,
  «Растяжка экрана», «Поменять кнопки лучей».
