# T7e: точность модели наложений (масштаб, значки, построчное сравнение)

Ветка: `t7c-overlap` · Статус: done · Размер: M
Зависит от: T7d

## Цель
Проверка наложений ловит реальный случай со скриншота владельца (подсказка на карте под значком A
и «Картой планеты») и не шумит там, где поля не видны вместе.

## Критерии приёмки
- [x] «повёрнутое» поле — только с настоящим поворотом; масштаб по оси (поля карты, 0,22) — не поворот
- [x] ширина `&image=`: ширина текстуры (`work/txtr_sizes.tsv`) × масштаб из тега; значок из твиков — 32 px (допущение)
- [x] каждая строка сравнивается со своим английским оригиналом; поля с переносом — по реальным строкам
- [x] касание ≤ 2 px шрифта — не наложение; прокрутка — высота окна; непереведённые строки — «проверить»
- [x] пары, не видимые вместе по коду, — `_exclusive`; неясные по FRME — `_unverified` («проверить в игре»)

## Проверка
- [x] модель повторяет скриншот: «Зафиксирована сейсмическая активность.» (418 px) касается «Выход» и значка A
- [x] `tools/test.sh` зелёный
- [x] подсказка на карте в две строки между «Выход» и значком (скриншот владельца)
- [x] «Карта мира» после перезапуска игры, HUD-подсказки в две строки (скриншоты владельца)

## Итог
- Подсказки на карте: предел 360 px на строку (место между «Выход» и значком A). 40 подсказок
  разбиты на две строки по словам с наименьшей шириной, без предлогов в конце строки.
- «Карта планеты» → «Карта мира» (World Map, точнее и не касается значка); «Карта региона» →
  «Карта зоны»; вопрос о выходе → «Выйти из Metroid? / Всё несохранённое пропадёт.» (5 строк налезали
  на «Да/Нет»).
- Значения настроек (`double0/1`, `triple0–2`) привязаны точно по коду, а не всем полям сразу.
- Вылет после Королевы-паразита — ошибка порта (`CStateManager.cpp:1443`, интерполяция актёров);
  в тестовом профиле `work/user` выключено `smooth_frames`. К моду отношения не имеет.

## Доработка по скриншотам (подсказки в HUD, окно подбора)
- Окно HUD-сообщения: 2 строки ≤ 256 px (3 строки касаются рамки, 4 — наезжают на полоску энергии;
  рамка изнутри ≈ 452 экранных px при масштабе 1,67 ≈ 270 px шрифта — расширять поле бессмысленно).
- Узкий шрифт и в окне HUD-сообщений (решение владельца): 13 из 23 подсказок влезли без правки
  текста; 10 переформулированы без потери смысла (список — в ответе владельцу, коммит).
- Окна подбора — FRME_MsgScreen, не HUD; страница в 3 строки чистая.
- Разделены пределы: `max`/`lines` — по замеченному сбою (ошибка), `seen_max`/`seen_lines` —
  «видели чисто» (превышение — «проверить в игре»).
- Найдено скриншотом: подписи «Вращать/Масштаб/Двигать» видны вместе со значком A и «Картой мира» —
  ложное исключение убрано; «Двигать» и значок — чисто (`_seen_clean`).
