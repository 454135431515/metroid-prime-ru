## Цель
Мод не добавляет в PAK новых ресурсов: на порте 0.31.1 игра с модом вылетала при разрушении ящика
(SIGSEGV в `CPakFile::SResInfo::GetType`, загрузка обломков `LoadDebrisExtended` → ресурс не найден),
без мода — нет (проверка владельца). Добавленные в NoARAM.pak id (узкий шрифт `52550001`/`52550002`
из T7d) — вторая ошибка порта с добавленными ресурсами после T5b.

- [x] узкий шрифт удалён; поле имени босса и HUD-сообщения сжаты по ширине правкой extentX в FRME
      (`squeeze` в `panes.json`): `CGuiTextPane::Draw` масштабирует ширину dimX / extentX отдельно от высоты
- [x] boss 1.11 (с округлением extentX до целого: «Королева-паразит» 159 px ≤ 160), hud-memo 1.1
- [x] валидатор считает ширины сжатых полей (`squeezed`); 0 ошибок

- [x] в игре: HUD-сообщение на 10% уже несжатого (скриншоты, тестовая user-папка)
- [ ] владелец: ящик и лифт без вылета с новым модом
