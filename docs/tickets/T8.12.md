# T8.12: титры и служебные строки

Ветка: `t8.12-credits` · Статус: done · Размер: S
Зависит от: T8.11

## Цель
Финальные титры (`STRG_Credits`; черновая копия `STRG_CreditsTest` — тем же способом) и последние
строки без слов. Концовки отдельного текста в STRG не имеют — только титры.

## Критерии приёмки
- [x] должности и заголовки переведены (41), имена — латиницей, как в оригинале; благодарности
      команды Retro переведены по фразам, имена в них не склоняются
- [x] иероглифы имён NCL в черновых титрах остаются со своим шрифтом `&font=30707C0C;`: валидатор
      больше не считает ошибкой знаки, которые есть в самом английском оригинале
- [x] «-- --», «[??????]», «Dolby» — без перевода (скопированы как есть)
- [x] 0 ошибок валидатора; переведено 2141 из 2141 строки
- [x] в игре: ширина длинных должностей в титрах («ВЕДУЩИЕ ТЕХНИЧЕСКИЕ ИНЖЕНЕРЫ») — титры целиком, концовка через консоль
- [x] вычитка владельцем (апрув 2026-10-25)
