# T8.13: хвост легенды карты остаётся на экране

Ветка: `t8.13-map-legend` · Статус: done · Размер: S
Зависит от: Tn

## Цель
Скрытая легенда карты не оставляет на экране конца строки («…ния» у левого края, скриншот владельца).

## Критерии приёмки
- [x] причина: легенда прячется сдвигом на фиксированное расстояние под английский текст (≤ 201 px),
      «— станция сохранения» — 248 px, видно «ния» (~33 px) → предел `map-legend` max 214
- [x] «— станция сохр.» (186), «— заправка ракет» (196); «— Плазменный луч» (207) помещается
- [x] 0 ошибок валидатора
