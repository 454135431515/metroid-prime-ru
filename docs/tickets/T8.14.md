# T8.14: авторство перевода в титрах

Ветка: `t8.14-credits-author` · Статус: done · Размер: S
Зависит от: T8.12

## Цель
В конце титров (`STRG_Credits` 324D0835:3, после строки о правах Nintendo) — кто перевёл и где
взять перевод.

## Решение
Три строки после трёх пустых: «РУССКИЙ ПЕРЕВОД», ник `454135431515`, адрес репозитория. Заголовок
без цвета: валидатор требует тех же тегов, что в английской строке, а заголовки должностей там
окрашены тегами.

## Критерии приёмки
- [x] валидатор: 0 ошибок (предупреждение о числе переносов ожидаемо)
- [x] ширина адреса 442 px шрифта титров меньше уже проверенной строки 598 px
- [x] в игре: строка видна и помещается (концовка через консоль)
