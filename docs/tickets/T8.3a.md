# T8.3a: Фрегат пиратов — сканы

Ветка: `t8.3a-frigate-scans` · Статус: done · Размер: M
Зависит от: Чекпоинт 3, T7e

## Цель
Все сканы Фрегата по-русски: пираты, паразиты, Мета Ридли, двери, терминалы, лаборатории.

## Критерии приёмки
- [x] 175 уникальных строк, 203 вхождения; термины и комнаты — в глоссарии
- [x] 0 ошибок валидатора
- [x] окно скана: оригинал сам выводит в нём до 5 строк (4 английских скана) — допуск поля; скан в 4 строки чистый (скриншот); 10 сканов сжаты до ≤ 5 строк

## Итог
- В координатах капсулы английский склеивает «110L.30L….Research» в одно слово; русское слово
  шире поля скана — пробел после многоточия (валидатор поймал).
- Хантер в журнале пиратов — «Охотница» (глоссарий: The Hunter).
- Допуск строк без замера — наибольшее число строк оригинала **в этом поле** (так поле задумано), не только
  у этой же строки.
- Сжато без потери смысла: «Изолятор образцов» (Specimen Solitary Holding) вместо «Одиночной камеры
  образцов», «Фазон >> уровень …», «Капсула N» в списке запусков, «Черепной кожух» (cerebral casing).
- Журнал (запись Королевы паразитов) листается страницами, ничего не обрезано (скриншоты).
