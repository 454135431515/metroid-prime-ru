# T8.3a: Фрегат пиратов — сканы

Ветка: `t8.3a-frigate-scans` · Статус: review · Размер: M
Зависит от: Чекпоинт 3, T7e

## Цель
Все сканы Фрегата по-русски: пираты, паразиты, Мета Ридли, двери, терминалы, лаборатории.

## Критерии приёмки
- [x] 175 уникальных строк, 203 вхождения; термины и комнаты — в глоссарии
- [x] 0 ошибок валидатора
- [ ] окно скана: сколько строк вмещает (57 сканов на строку длиннее оригинала) — скриншот

## Итог
- В координатах капсулы английский склеивает «110L.30L….Research» в одно слово; русское слово
  шире поля скана — пробел после многоточия (валидатор поймал).
- Хантер в журнале пиратов — «Охотница» (глоссарий: The Hunter).
