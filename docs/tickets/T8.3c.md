# T8.3c: окно скана — 4 строки, «Вид:», подсказки HUD Фрегата

Ветка: `t8.3c-scan-4-lines` · Статус: done · Размер: M
Зависит от: T8.3a, T8.3b

## Цель
Сканы и подсказки Фрегата не выходят за рамки окон (скриншоты владельца в родном 640×480).

## Критерии приёмки
- [x] окно скана: жёстко 4 строки — пятая уходит под нижнюю рамку и значок кнопки (скриншоты);
      рамка изнутри кончается на 486 px, перенос на 286 px шрифта даёт ~479 — расширять некуда
- [x] Morphology → «Вид:» во всех сканах (решение владельца): «Вид: Космический пират» в одну строку
- [x] 12 длинных сканов и 12 подсказок HUD сжаты без потери фактов; 0 ошибок валидатора

## Итог
- Жёсткий предел (по замеченному сбою) превышать можно только если сама эта строка оригинала его
  превышает; допуск «максимум оригинала в поле» — только для полей без замера (он и прятал
  переполнения сканов и подсказок).
- Сообщения станций сохранения — окно сообщений (`message-box-memo`), не HUD: правило `exclude`.
