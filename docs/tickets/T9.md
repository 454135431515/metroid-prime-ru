# T9: надписи на текстурах — ЭНЕРГИЯ, НАЖМИТЕ START, ДАЛЕЕ / ВЫХОД / НАЗАД

Ветка: `t9-hud-textures` · Статус: review · Размер: S
Зависит от: T7f

## Цель
Английские слова, нарисованные на текстурах (их нет в STRG), — по-русски: «[ ENERGY ]» над полоской
энергии (TXTR `BCBA7570`), «[ PRESS START ]» на титульном экране (`D411B6BB`, TXTR_PressStart),
«NEXT / BACK / EXIT» внизу паузы (`89E7453F`).

## Решение
Порт подменяет текстуру файлом `<id TXTR>.dds` в моде (native texture). `tools/hud_textures.py` рисует
текстуру заново глифами нашего Deface24B (кириллица), уменьшенными до высоты букв оригинала
(14/16 px), со сглаживанием; места замерены по дампу `MP_DUMP_TEXTURES`. id найдены по
`tools/extract_textures.py` порта (index.tsv). Сборка мода вызывает генератор сама.

## Критерии приёмки
- [x] три DDS (DX10 RGBA8, мипы) в моде, лог порта: `3 native texture(s)`
- [x] в игре (порт 0.33.1): титульный экран, HUD, пауза — надписи на местах, ориентация верная
- [x] `test_build_mod` проверяет заголовки DDS
- [ ] владелец: вид надписей
