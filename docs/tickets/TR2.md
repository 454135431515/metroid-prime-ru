# TR2: HD-шрифт с кириллицей для импорта Remastered

Ветка: `tr2-hd-font` · Статус: done · Размер: M
Зависит от: T4, ADR 0004

## Цель
С импортом Remastered порт рисует текст полем расстояний `font/deface.sdfont` (195 символов, без
кириллицы); русские буквы при этом откатываются на растровый шрифт диска. Нужен тот же HD-шрифт
с русскими буквами — и только при наличии импорта: без Remastered игра остаётся растровой.

## Решение
`tools/hd_font.py`: латинские глифы шрифта импорта восстанавливаются в 4 раза крупнее, русские
собираются рецептами `tools/cyrillic.py` (копии, зеркала, конструкторы по меркам H) и переводятся
обратно в поле расстояний; латиница и раскладка атласа не меняются, новые глифы — полками ниже.
Мелкие отступы рецептов заданы в пикселях растрового шрифта (`cyrillic.UNIT`, 1 для растровых,
масштаб стема для HD); растровые шрифты от этого не изменились (побайтно).

`tools/build_mod.py` пишет `mod/russian/font/deface.sdfont`, только если рядом есть
`mod/remastered-models/font/deface.sdfont`. Шрифт Nintendo в git не попадает: строится у владельца.

## Критерии приёмки
- [x] превью: все буквы, хвосты Д/Ц/Щ, ё/й
- [x] `test_cyrillic`: латиница побайтно та же, все русские буквы в атласе
- [x] в игре с Remastered (меню, HUD, пауза, карта): HD-кириллица, без отката на растр; прогон 276 комнат — 0 вылетов
- [x] без Remastered: мод без `font/`, игра как раньше
- [x] строчная п — сжатая N (копия n читалась как л)

Карта с импортом Remastered не рисуется и без нашего мода — баг порта (issue #207 Odrannnn/MetroidPrimePort).
