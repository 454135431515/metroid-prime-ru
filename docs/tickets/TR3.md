# TR3: HUD и карта Remastered вместе с переводом

Ветка: `tr3-hud-frames` · Статус: done · Размер: S
Зависит от: T7f, TR2

## Цель
С импортом Remastered работают его HUD, мини-карта и экран карты; без импорта (переключатель
графики порта v0.35) — наши сжатые поля.

## Причина
Импорт Remastered кладёт свои кадры HUD (`hud/<id>.FRME`, 14 штук) — порт берёт их как обычные
ресурсы мода. Наши пять кадров (копии с диска со сжатыми полями, T7f) лежали в `russian`, который
грузится после `remastered-models`, и перекрывали кадры Remastered: мини-карты нет, экран карты
пустой. Найдено делением мода на части: со всем, кроме FRME, карта есть; с одним
`2F972D0C` (FRME_BaseHud) — нет. Пропуск HUD в импорте (`remastered_skip=hud`) ни при чём: в логе
импорта HUD всё равно «reused».

## Решение
`build_mod.py` пишет кадры в отдельный мод `hud-russian` рядом с `russian`. По имени он раньше
`remastered-models`: с импортом выигрывают кадры Remastered, без него — наши. Поля Remastered шире
дисковых: HUD-сообщения, пауза и журнал под Remastered помещаются без сжатия.

## Критерии приёмки
- [x] Remastered + перевод: карта (16% кадра), мини-карта, сообщение, пауза, журнал — скриншоты
- [x] Remastered выключен: `hud-russian` отдаёт 5 кадров, сообщение в 2 строки, карта дисковая
- [x] `test_build_mod`: кадров в `russian` нет, `hud-russian` < `remastered-models` < `russian`
