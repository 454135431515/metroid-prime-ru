# Глоссарий EN → RU

Источник: русская фанатская Metroid Wiki (metroid.fandom.com/ru) — соответствие статей RU↔EN через MediaWiki API
(только названия). «вики» — название оттуда, приведённое к правилам ADR 0003 (регистр, ё, слитное «супер-»);
«своё» — на вики нет, перевод по ADR 0003. Перевод обязан использовать эти формы; склонение — по-русски.

Спорные места — внизу, решаются на Чекпоинте 2.

## Формы для кнопок паузы (≤ 117 px на строку, ≤ 2 строк; решение владельца 2026-10-22)

Только в кнопках снаряжения/настроек (`500EC6A0`), в остальных текстах — полные формы:
Power Suit → «Энергокостюм» (Энерго-/костюм); Power Beam → «Энерголуч» (Энерго-/луч);
Scan Visor → «Забрало-сканер»; Space Jump Boots → «Космоботинки» (Космо-/ботинки);
Secondary Items → «Доп. предметы»; Controller → «Геймпад»; Visor/Helmet Opacity → «Плотность
забрала/шлема»; Swap Beam Controls → «Раскладка лучей». Пункты настроек (`500EC6A0:16–35`) общие с
меню настроек главного экрана — без ручных переносов.
